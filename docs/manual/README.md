# Manual de uso del ERP (borrador)

Aquí se van juntando, por área, los procesos que conviene explicar paso a paso cuando se
arme el manual de uso. Cada página está escrita para quien usa el ERP (no para sistemas) y
dice qué hacer, quién lo hace y qué pasa después. Lo que cuenta cada página sale de cómo
funciona el ERP hoy; si cambia una regla, se corrige aquí en el mismo cambio.

Dentro del ERP, el botón del birrete (modo tutorial) explica cada pantalla. El manual no lo
repite: cuenta los procesos completos, que cruzan varias pantallas y varias personas.

| Área | Página | Qué trae |
|---|---|---|
| Ventas | [ventas.md](ventas.md) | Números de pedido (PED-26-799, Mercado Libre y web) · Entregar un pedido y la hoja de salida · Cuándo sale un equipo · Ventas de Mercado Libre (pago, lo que se queda ML, envío) |
| Producción | [produccion.md](produccion.md) | Equipos de stock: fabricarlos y venderlos · Cuadrillas y terminal de piso · Gantt (también en la ficha del pedido y la orden) · La TV del taller · Personal de piso · Métricas |
